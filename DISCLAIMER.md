# Disclaimer

This skill provides **technical security analysis** of Solana programs through automated tooling, manual review checklists, formal verification guidance, and economic attack simulation.

## What This Skill Is

- A technical tool to help developers find and fix security vulnerabilities in Solana programs
- A structured methodology for systematic code review
- A guide for running security tools and interpreting their output
- A framework for threat modeling and economic attack simulation

## What This Skill Is NOT

- **A replacement for a professional audit firm.** Critical programs handling significant value should always engage a reputable audit firm for a comprehensive review.
- **A guarantee of bug-free code.** No automated or AI-assisted tool can guarantee the absence of vulnerabilities.
- **Legal advice.** For legal and compliance questions, route to `crypto-legal-skill` or retain licensed counsel.
- **A deployment tool.** This skill analyzes code; it does not deploy, upgrade, or interact with on-chain programs.
- **A real-time monitoring or intrusion detection system.**

## Best Practices

1. **Always engage a professional audit firm** for programs handling >$10K TVL before mainnet deployment.
2. **Use this skill as a pre-audit tool** to find and fix issues before engaging a firm — this saves time and money.
3. **Use this skill as a post-audit tool** to understand and track remediation of professional audit findings.
4. **Never rely solely on automated tools.** Manual review and economic analysis are essential.
5. **Keep dependencies updated.** Security is a continuous process, not a one-time event.
