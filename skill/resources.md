## Notable Exploit Post-Mortems

- **Wormhole ($326M):** Missing signature verification on guardian set update
- **Cashio ($48M):** Missing signer check on vault withdrawal
- **Crema Finance ($8.8M):** Flash loan + rounding error
- **Mango Markets ($116M):** Oracle manipulation
- **Raydium ($2M):** Owner-only function missing access control
- **Solend:** Oracle manipulation via illiquid market
